Boost Property Map Library

(From https://www.boost.org/doc/libs/latest/libs/property_map/doc/property_map.html)

Property maps are statically-typed entities. If you need to access property maps in a more dynamic setting (e.g., because you're reading an unknown set of attributes from a file), you can use the dynamic_properties class to access a set of property maps through a dynamically-typed interface.
